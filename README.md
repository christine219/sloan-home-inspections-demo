# Sloan Home Inspections demo

This is a static demo copy of the Sloan Home Inspections website, prepared for GitHub Pages. It does not change the live site.

The website files are at the repository root. To preview locally, run a static web server from this directory (for example, `python -m http.server 8000`) and open `http://localhost:8000/`.

The demo includes the same public-facing scheduling and contact links as the live site. Its `robots.txt` blocks indexing.
